/review-plan [plan-path]

現在のプロジェクト計画を OpenAI Codex CLI に送信し、第三者視点のレビューを取得して表示する。

目的:
- Claude Code が作成した plan mode の計画を、別の AI エージェントにレビューさせる
- 見落とし、リスク、Phase 分割の問題、テスト不足を早期に見つける

引数:
- `plan-path` を指定した場合は、そのファイルをレビュー対象にする
- 引数がない場合は `~/.claude/plans` 配下の最新の `.md` ファイルをレビュー対象にする

注意:
- 引数なし時の「最新ファイル」は便宜上のフォールバックであり、「現在使用中のプラン」を厳密に示すものではない
- このコマンドはレビュー専用であり、コードの編集・コミット・プッシュは行わない
- Codex には最小限の権限（read-only sandbox）のみを与える

以下の手順で実行する:

1. 対象プランファイルのフルパスを決定する。
   - 引数があればそのパスを絶対パスに解決する
   - 引数がなければ `~/.claude/plans/*.md` から更新日時が最も新しいファイルを選ぶ
   - ファイルが存在しない場合は、理由を明示して終了する
   - `.md` 以外が指定された場合は、その旨を伝えて終了する

2. CLAUDE.md のフルパスを収集する。
   - プロジェクトルートの `CLAUDE.md` が存在すればそのフルパスを取得する
   - `~/.claude/CLAUDE.md`（グローバルルール）も存在すればそのフルパスを取得する
   - いずれも存在しない場合は ref 参照なしで続行する

3. Codex CLI でレビューを実行する。
   - 実行ファイルの解決順序:
     1. `/opt/homebrew/bin/codex` が存在すればそれを使う
     2. 存在しない場合は `command -v codex` でフォールバックを試みる
     3. どちらも見つからない場合はエラーを表示して終了する
   - **初回レビュー**は以下のコマンドを実行する:
     ```bash
     codex exec -m gpt-5.3-codex "このプランをレビューして。琑末な点へのクソリプはしないで。致命的な点だけ指摘して: {plan_full_path} (ref: {CLAUDE.md full_path})"
     ```
   - **プラン更新後の再レビュー**（前回レビューのコンテキストを引き継ぐ）は以下を使う:
     ```bash
     codex exec resume --last -m gpt-5.3-codex "プランを更新したからレビューして。琑末な点へのクソリプはしないで。致命的な点だけ指摘して: {plan_full_path} (ref: {CLAUDE.md full_path})"
     ```
     - `resume --last` を付けないと最初のレビューの文脈が失われるため必須
   - `-m gpt-5.3-codex` でモデルを必ず指定すること
   - `codex exec` の終了コードが非ゼロの場合は、終了コードを明示してエラーを表示する

4. レビュー結果を表示する。
   - Codex の出力を以下の形式で会話に出力する（本文は無加工・省略禁止）:
     ```
     ---
     ## Codex レビュー結果

     （Codex の出力をここに無加工で出力）
     ---
     ```
